# Contributing

Contributions to documentation, model cards, benchmark charts, and tooling are welcome.

## Before opening a pull request

- Keep English and Russian documentation in sync.
- Link the base model, model weights, benchmark chart, and applicable licenses.
- Describe the actual training and merging steps; do not imply unrun evaluations.
- For benchmark updates, include the task, metric, dataset and split, evaluation configuration, sample count, and source.
- Confirm that contributed assets and code may be redistributed under the repository's GPL-3.0 license. Model weights and upstream materials may have separate licenses; document those separately.
- Do not commit model weights, datasets, credentials, or private training artifacts.

## Pull requests

Keep each pull request focused. Explain the change and include relevant validation, such as checking local links, SVG rendering, or generated benchmark data.
